# Mushaf M1 data attribution

The QCF V2 page glyph map and surah-start map in this folder are sourced from the public
`mohammed-2-5/islamic-library-data` dataset. Its README describes Quran text/data as
public-domain classical text and code/scripts as MIT-licensed.

The page reader loads QCF V2 page fonts at runtime from the documented Quran Foundation
font CDN. Font files are not bundled into this repository.

Sources:
- https://github.com/mohammed-2-5/islamic-library-data
- https://api-docs.quran.com/docs/tutorials/fonts/font-rendering/
